# GovGuard AI v1.0.0 — 피처 명세서

본 문서는 `scripts/gov_v1_0_0.py`로 학습된 **GovGuard AI v1.0.0**
(`models/gov_model_v1.0.0.pkl`)을 설명합니다.

> InsureGuard(보험)와 같은 패키지 양식이며, **지자체**용입니다.  
> 버전은 `gov_1.0.0`부터 시작합니다.  
> **후속:** 중대사고·경중은 **v1.0.1**, EB·반기는 **v1.0.2**.  
> 현재 `src/gov_inference.py`는 **v1.0.2**을 로드합니다.

## 1. 모델 개요

| 항목 | 내용 |
|------|------|
| 모델명 | GovGuard AI |
| 버전 | 1.0.0 |
| 용도 | 지역별 **다음 분기 사고율** 예측 |
| 학습 데이터 | `data/raw/사고분석_2016~2025_원본합본.csv` |
| 회귀기 | `HistGradientBoostingRegressor` |
| 사용자 입력 | **없음** (성별·연령·차종 등 인구통계 입력 X) |

학습 지표 (time split, next∈2024–2025):

| 지표 | 값 |
|------|-----|
| R² | **0.956** |
| RMSE | 0.0128 (비율 스케일) |
| MAE | 0.0093 (**0.93%p**) |

### 사고율 정의

$$
\text{사고율}_{r,t} = \frac{\text{지역 } r \text{ 의 } t \text{ 분기 사고건수}}{\text{대구 전체 } t \text{ 분기 사고건수}}
$$

즉 해당 분기에 대구 사고 중 **그 지역이 차지하는 비율(점유율)** 입니다.  
(인구·등록대수 노출 보정은 v1.0.0에 포함하지 않음)

## 2. 데이터 흐름

1. 원천 CSV → `지역`(시군구) + `연도`/`분기` 파싱  
2. `지역 × 연도분기`로 집계 → 사고건수·사고율 패널  
3. 시계열 피처(현재·lag·롤링) 생성  
4. 타깃 = **다음 분기 사고율** (`shift(-1)`)  
5. 시간 분할: next 타깃 연도가 2024–2025이면 test

```text
[t 분기 피처]  →  모델  →  [t+1 분기 사고율]
```

---

## 3. 모델 피처 (자동 생성)

사용자 API 입력이 아니라, 패널에서 만들어지는 피처입니다.

| 피처 | 설명 |
|------|------|
| `지역_code` | 지역 LabelEncoder |
| `분기` | 1–4 |
| `연도_idx` | 시작 연도 대비 인덱스 |
| `rate_t` | 현재 분기 사고율 |
| `rate_lag1`~`4` | 1~4분기 전 사고율 |
| `count_t` | 현재 분기 사고건수 |
| `count_lag1`~`2` | 1~2분기 전 건수 |
| `rate_roll4` / `count_roll4` | 직전 최대 4분기 평균 |

## 4. 추론

인구통계 입력 없이, 저장된 최신 패널 기준으로 다음 분기를 예측합니다.

```bash
python -m scripts.gov_v1_0_0
```

코드 예:

```python
from src.gov_inference import predict_gov_rates

# 전 지역
predict_gov_rates()

# 특정 지역
predict_gov_rates(지역="중구")

# 기준 분기 지정
predict_gov_rates(지역="달서구", as_of_연도분기="2025Q2")
```

출력 필드 예: `지역`, `기준분기`, `예측분기`, `예측사고율`, `예측사고율_퍼센트`, `추정_다음분기사고건수`
