# InsureGuard AI v1.0.2 — 피처 명세서 & R² 해석 가이드

본 문서는 `scripts/archive/ins_v1_0_2.py`로 학습된 **InsureGuard AI v1.0.2**
(`models/ins_model_v1.0.2.pkl`)의 입력·타깃 정의와 R² 해석을 설명합니다.

> **후속 버전:** 사고 **빈도**는 **v1.0.3**, 군위 2016~ 포함은 **v1.0.4**.  
> (`scripts/ins_v1_0_4.py`, `docs/ins_v1_0_4_feature_spec.md`)  
> 현재 API 서빙 기본 모델은 v1.0.4입니다.

> **핵심 한 줄:**  
> R²가 높은 이유는 “개별 사고의 경중을 잘 맞췄기 때문”이 아니라,  
> **타깃 자체가 입력 4개로 정해지는 프로파일 기대위험**이라서  
> 모델이 거의 결정적 함수를 학습하기 때문입니다.

## 1. 모델 개요

| 항목 | 내용 |
|------|------|
| 모델명 | InsureGuard AI |
| 버전 | 1.0.2 |
| 용도 | 보험 인수·요율 참고용 프로파일 위험 점수 (**심각도 중심**) |
| 학습 데이터 | `data/raw/사고분석_2016~2025_원본합본.csv` |
| 회귀기 | `HistGradientBoostingRegressor` |
| 분류기 | 법규위반 Top3 / 사고경중 비율 (`RandomForestClassifier`) |

| 지표 | 값 | 의미 |
|------|-----|------|
| **R²** | **0.990** | 프로파일 위험점수 회귀 적합도 |
| RMSE | 2.87 | 0~100 점수 스케일 오차 |
| MAE | 1.68 | 평균 절대 오차 |
| 법규위반 Acc. | 54.6% | 개별 사고 법규 라벨 (별도 과제) |
| 사고경중 Acc. | 68.0% | 개별 사고 경중 라벨 (별도 과제) |

가중치: `SEVERITY_BLEND=0.72`, `GROUP_BLEND=0.28` (빈도 미반영)

---

## 2. 입력 피처 (Features)

### 2.1. 사용자 입력 (4개)

| 피처명 | 원본 컬럼 | 예시 |
|--------|-----------|------|
| 성별 | `가해운전자 성별` | `남`, `여` |
| 연령 | `가해운전자 연령대` | `21-30세` |
| 차종 | `가해운전자 차종` | `승용` |
| 지역 | `시군구` → `지역` | `북구`, `중구` |

### 2.2. 교차 피처 (6개)

성별×연령, 연령×차종, 성별×차종, 지역×차종, 지역×연령, 성별×지역  
→ 모델 입력 총 **10개**.

---

## 3. 위험점수 타깃 (심각도만)

$$
\text{score}_g = 0.72\cdot \log(1+\widetilde{\text{EPDO}}_g) + 0.28\cdot (10\cdot \widetilde{p}^{\text{severe}}_g)
$$

$$
\text{위험점수}_g = \text{PercentileRank}(\text{score}_g) \times 100
$$

EPDO·Empirical Bayes(`prior_strength=40`) 정의는 v1.0.3 문서와 동일합니다.  
**차이:** v1.0.2는 사고 건수(빈도)를 최종 점수에 넣지 않습니다.  
→ 예: `남|21-30세|승용|중구`는 심각도 하위권(~6점대)으로 나올 수 있습니다.

---

## 4. R² 해석

R²는 **프로파일 스코어카드 재현도**이지, 개별 사고 예측 정확도가 아닙니다.  
대외 표기: “R² ≈ 0.95 = 사고 예측 95%”로 쓰지 말 것.
