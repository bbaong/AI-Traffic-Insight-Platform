# InsureGuard v1.0.5 — Frontend 인수인계

`frontend/` 는 이 작업에서 **수정하지 않았습니다.**  
AI `POST /predict` 응답에 필드가 추가됐고, 기존 필드는 그대로입니다. Backend는 AI JSON을 그대로 넘깁니다.

명세: [`ins_v1_0_5_feature_spec.md`](ins_v1_0_5_feature_spec.md)

---

## 1. 호환

프론트를 안 바꿔도 상담 Step1은 동작합니다.

- `위험도` / `예측등급` / `등급확률` / `사고경중비율` / `담보추천` 유지
- 게이지는 계속 `위험도` 하나만 쓰면 됨
- 다만 **점수 의미가 바뀜** (아래 3절). 캡션만 먼저 바꿔도 됨

`variant`가 `ins_v1.0.4` → `ins_v1.0.5` 인지로 신필드 노출 여부를 갈라도 됩니다.

---

## 2. 권장 UI (Step1 `AiAnalysisResultCard`)

게이지는 **하나**. 바로 아래에 발생·심도 2칸 + 상담 문구.

```
[칩: 구군 · 연령 · 성별 · 차종]

[게이지  위험도 / 100   등급]     [법규위반 TOP3 = 등급확률]
 캡션: 유사 프로필 기대손실 순위

 발생 위험  ████░  {발생위험.라벨}     심도 위험  ██░░░  {심도위험.라벨}
            {발생위험.설명}                     {심도위험.설명}

[표준 6대 담보 추천]  ← 담보추천 그대로

상담 포인트 — {상담포인트}   ← 프론트에서 문장 새로 짜지 말 것
```

막대 너비: `발생위험.점수`, `심도위험.점수` (0~100).  
색은 기존 등급 팔레트(`LOW`/`MODERATE`/`HIGH`/`CRITICAL`)와 동일.

고객 목록·PDF 표지 점수는 계속 `위험도` 하나.

---

## 3. 필드

### 유지

| 필드 | 쓰임 | 주의 |
|------|------|------|
| `위험도` | 게이지 | **기대손실 순위**. 예전 심각도70+건수30 아님 |
| `예측등급` | 뱃지 | 임계 75/50/30 동일 |
| `등급확률` | TOP3 | 키=법규명, 값=0~1 (×100 해서 % 표시 — 지금과 동일) |
| `사고경중비율` | (카드에 아직 없음) | 0~1 |
| `담보추천[]` | 6대 담보 | `script` / `reason` 유지 |

### 신규 (선택 표시)

```ts
type RiskAxis = {
  점수: number;   // 0~100 백분위
  등급: 'LOW' | 'MODERATE' | 'HIGH' | 'CRITICAL';
  라벨: '낮음' | '보통' | '높음' | '위험';
  설명: string;  // 막대 아래 한 줄
};

// 응답 추가
발생위험: RiskAxis;
심도위험: RiskAxis;
상담포인트: string;      // AI가 이미 한국어 문장
발생률_1만명당?: number; // 연간, 참고. 기본 UI에는 안 넣어도 됨
```

`buildConsultPoint()` 프론트 조합은 **쓰지 말고** `상담포인트`를 그대로 출력하세요.  
발생×심도 2×2 문장은 AI `src/consult_copy.py`에 있습니다.

## 4. 카피 (이미 API에 포함)

| 발생 \ 심도 | 낮음·보통 | 높음·위험 |
|-------------|-----------|-----------|
| 낮음·보통 | 기대손실 낮음. 특약·기존 담보 점검 | 자주 안 나지만 한 건이 큼. 대인 한도·자기신체 |
| 높음·위험 | 잔사고 많음. 자차·대물 검토 | 둘 다 높음. 인수 신중 + 한도 확대 |

게이지가 CRITICAL 이면 문장 끝에 인수 재확인 한 줄이 붙습니다.

캡션 교체:

- 이전: `유사 프로필 기준 상대 위험도입니다`
- 권장: `유사 프로필 기대손실 순위입니다`

## 5. 점수 해석 (QA·상담 교육)

남 / 51-60세 / 승용 기준 대략값:

| | v1.0.4 | v1.0.5 게이지 | 발생 | 심도 |
|--|--------|---------------|------|------|
| 수성구 | ~53 | ~90 CRITICAL | 매우 잦음 | 보통 |
| 군위군 | ~92 | ~94 CRITICAL | 보통 | 매우 무거움 |

수성 점수가 올라가는 것은 버그가 아닙니다. **인구 대비 사고가 잦아** 기대손실이 큽니다.  
게이지만 보면 둘 다 위험으로 보이므로, **반드시 발생/심도 2칸**을 같이 보여 주세요.

`발생률_1만명당`을 화면에 쓸 경우: “연간, 해당 성별·연령 주민 1만 명당 이 차종 사고 건수(근사)”로 툴팁. 차종 분모는 인구라 절대 비교용이지 등록대수 기준이 아닙니다.
