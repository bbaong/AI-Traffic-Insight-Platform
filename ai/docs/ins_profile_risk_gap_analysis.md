# InsureGuard — 수성구 vs 군위군 위험점수 분해 & 법규위반 TOP3 해석

> **프로파일:** 남 / 51-60세 / 승용  
> **모델:** `ins_model_v1.0.4.pkl`  
> **분석 스크립트:** `scripts/analyze_profile_risk_gap.py`

---

## 1. 결론 한 줄

**38점 차이(53 vs 91.6)는 버그가 아니라, 군위군 프로파일의 중대율(46.8%)이 수성구(25.1%)보다 훨씬 높아 **심각도 순위**가 99.5 vs 32.9로 벌어진 결과다.**  
빈도(사고 건수)는 오히려 **수성구가 더 높다**(n=1,868 vs 62).

법규위반 TOP3에 “위험도 표시”를 UI에 추가하는 것보다, **지금 구조(경중 비율 + 담보 규칙)를 유지**하는 편이 타당하다.

---

## 2. 위험점수 분해 (학습 타깃 기준)

산식 (`ins_v1_0_4.py`):

```
위험점수 = 0.70 × 심각도순위 + 0.30 × 빈도순위
```

| 항목 | 수성구 | 군위군 | 차이(군위−수성) |
|------|--------|--------|----------------|
| **pkl 추론 위험도** | **53.0** (HIGH) | **91.6** (CRITICAL) | **+38.6** |
| 사고 건수 n | 1,868 | 62 | −1,806 |
| raw 중대율 (사망+중상) | 25.1% | **46.8%** | **+21.7%p** |
| smooth EPDO | 16.95 | 25.17 | +8.2 |
| smooth 중대율 (EB) | 25.1% | 38.7% | +13.6%p |
| **심각도 순위 (0~100)** | 32.9 | **99.5** | **+66.5** |
| **빈도 순위 (0~100)** | **99.2** | 72.8 | **−26.5** |
| 타깃 기여 (0.7×심각+0.3×빈도) | 52.8 | 91.4 | +38.6 |
| 전체 911 프로파일 중 순위 | 상위 43% | **상위 1.4%** | — |

### 해석

1. **차이의 대부분은 심각도 순위**에서 발생 (66.5p). 군위는 “같은 프로파일”이라도 **중대·사망 비율이 높은 사고**가 많다.
2. **빈도는 수성이 더 높음** — 10년치를 넣어도 군위 n=62는 대구 전체 프로파일 중 **절대 건수는 적다**. 빈도 30% 가중이 있어도 군위 점수를 **올리는** 요인은 아니다.
3. 10년 데이터 반영의 효과: 군위 **과소·EB 당김 → 실제 고중대율 반영** → 심각도 순위 상승. “데이터 넣었는데 점수가 낮아져야 한다”는 기대와는 **반대 방향**이 정상이다.

## 4. 법규위반별 실적 중대율 (동일 프로파일, n≥3)

TOP3 **빈도**와 **중대율**이 항상 같지 않다.

**수성구** (n=1,868)

| 법규위반 | n | 중대율 |
|----------|---|--------|
| 보행자보호의무위반 | 82 | **51.2%** |
| 중앙선침범 | 25 | 44.0% |
| 신호위반 | 145 | 39.3% |
| 안전운전불이행 | 1,124 | 22.2% |

**군위군** (n=62, 표본 작음)

| 법규위반 | n | 중대율 |
|----------|---|--------|
| 신호위반 | 5 | 60.0% |
| 안전운전불이행 | 30 | 43.3% |
| 중앙선침범 | 15 | 40.0% |

- 수성: TOP1 **안전운전불이행**은 건수는 많지만 중대율 22%로 낮음.
- 군위: TOP2 **중앙선침범**은 건수·확률 모두 높고, 중대율도 40%대.

## 5. 법규 TOP3에 “위험 표시”를 UI에 넣어야 하나?

### 권장: **UI 표시 추가는 하지 않는다**

| 이유 | 설명 |
|------|------|
| TOP3의 의미 | **“이 프로파일에서 어떤 위반이 자주 나오는가”** (분류 확률). Acc. ~55% — 개별 사고 라벨 예측 |
| 위험점수와 분리 | 위험점수는 **심각도+빈도 순위**. 법규 TOP3는 **별도 분류기** 출력 |
| 중대 연계는 이미 있음 | **사고경중 비율**, **위험점수**가 결과 심각도를 반영 |
| 담보 로직 | `coverage_rules.py`가 안전운전불이행·신호위반·안전거리미확보 **확률**로 담보 권고 (UI 뱃지 아님) |
| 오해 위험 | “빨간 위반” = 더 위험으로 읽히지만, **빈도 1위 ≠ 중대율 1위** (수성 사례) |

### 타당한 대안 (UI 장식 대신)

| 우선순위 | 방안 | 비고 |
|----------|------|------|
| 1 (현状 유지) | TOP3 = 경향, 경중·위험점수 = 심각도 | 상담 문구만 보강 |
| 2 | **상담 포인트**에서 지역·경중 기반 문장 생성 | 이미 담보 `reason`에 확률·등급 |
| 3 (모델 v1.0.5+) | TOP3를 **P(위반\|프로파일)** 유지 + API에 `중대연계_참고` (실적 중대율) **별도 필드** | UI 색칠 없이 숫자 1줄 |
| 4 (비권장) | 위반 종류별 고정 “위험 등급” 테이블 | 신호=높음 등 — 데이터·지역마다 깨짐 |

**UI에서 위반 항목에 위험 뱃지를 붙이는 것**은 빈도와 심각도를 섞어 **상담사·고객이 오해**하기 쉽다.  
변경이 필요하면 **API/상담 텍스트** 또는 **v1.0.5에서 TOP3 산출 정의**를 손보는 쪽이 낫다.

## 6. “차이를 줄이고” 싶다면 (모델/산식)

UI·법규 표시가 아니라 **점수 산식** 문제:

| 방향 | 효과 |
|------|------|
| 지역 효과 완화 | 대구 평균 대비 편차만 반영 |
| 빈도를 발생률로 | 인구·등록대수 보정 (군위 n 작음 완화) |
| `FREQ_BLEND` ↓ | 건수 순위 영향 축소 (현재 군위는 빈도가 점수를 **깎는** 쪽) |
| 심각도 EB `prior_strength` ↑ | 희소 프로파일(군위 n=62) 극단값 완화 — **91.6을 소폭 내릴 수 있음** |

10년치 적재는 **정상 반영**됐고, 점수 격차는 **군위 고중대율**이 설계대로 반영된 결과다.
