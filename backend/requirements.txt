# ============================================
# Backend 설치 가이드 (처음 설치하는 경우)
# ============================================
# 사전 요구사항: Node.js 18 이상, npm
# 작업 디렉터리: AI-Traffic-Insight-Platform/backend
#
# 1) 의존성 설치
#    npm install
#
# 2) 환경 변수 파일 생성
#    backend 폴더에 .env 파일을 만들고 아래 내용을 채워 넣으세요.
#
#    DATABASE_URL="mysql://USER:PASSWORD@HOST:3306/DATABASE_NAME"
#    JWT_SECRET=your_jwt_secret
#    JWT_ACCESS_EXPIRATION=1800000
#    JWT_REFRESH_EXPIRATION=604800000
#
# 3) Prisma Client 생성 (필수)
#    npx prisma generate
#
# 4) 개발 서버 실행
#    npm run dev
#
#    서버 주소 예: http://localhost:5000
#
# --- 기타 자주 쓰는 명령어 ---
#    npm run build          # TypeScript 빌드
#    npm start              # 빌드 결과로 서버 실행
#    npx prisma db pull     # DB 스키마를 prisma/schema.prisma로 가져오기
#    npx prisma generate    # 스키마 변경 후 Client 재생성
#
# 참고:
# - 이 프로젝트는 Node.js 기반입니다. pip install이 아니라 npm install을 사용합니다.
# - 패키지 설치 후 반드시 npx prisma generate를 실행해야 서버가 정상 동작합니다.
# - Prisma Client는 src/generated/prisma 경로에 생성됩니다.
# ============================================
