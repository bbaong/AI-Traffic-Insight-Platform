# 프론트엔드 폴더 구조 (현재)

기준 경로: `frontend/`  
작성 기준: **2026-07-31** 도메인 재배치 이후 디스크 상태  
(`node_modules/`, `dist/` 제외)

이 문서는 **지금 실제로 있는 파일**을 기준으로, 폴더·파일별 역할을 정리한 것이다.

---

## 1. 한눈에 보는 역할 분담

| 영역 | 경로 | 하는 일 |
|---|---|---|
| 앱 골격 | `src/app/` | 최상위 App, 라우터, 로그인·역할 가드 |
| 도메인 | `src/domains/` | 업무 단위 화면·API·컴포넌트 (`auth` / `gov` / `ins`) |
| 공용 | `src/shared/` | 여러 도메인이 쓰는 UI·레이아웃·상수·타입·훅·유틸 |
| 페이지(비도메인) | `src/pages/` | 랜딩·마이페이지·설정·개발용 화면 |
| 잔여(보류) | `src/stores/`, `src/mocks/`, `src/api/` | 아직 루트에 남은 스토어·목업·백업 |
| 스타일 | `src/styles/` | 디자인 토큰·전역 CSS |
| 진입 | `src/main.tsx` | React 마운트 |

### 역할 구분 가이드

- **도메인 화면** → `domains/{auth,gov,ins}/pages`
- **랜딩·마이·설정** → `pages/`
- **GOV/INS가 같이 쓰는 대시보드 카드·헤더·사이드바** → `shared/`
- **로그인 상태(Zustand)** → 아직 `stores/authStore.ts` (보류 위치)

## 3. `frontend/` 루트

```
frontend/
├── docs/                 # 설계·작업 기록 문서
├── public/               # 정적 파일 (빌드 시 그대로 복사)
├── src/                  # React 앱 소스 (핵심)
├── .env / .env.example   # Vite 환경변수 (카카오 키, API URL 등)
├── index.html            # SPA 진입 HTML
├── package.json          # 의존성·스크립트
├── package-lock.json     # 잠금 파일
├── vite.config.ts        # Vite 설정
├── tsconfig*.json        # TypeScript 설정
├── eslint.config.js      # ESLint
└── README.md             # 프로젝트 소개
```

| 항목 | 역할 |
|---|---|
| `docs/` | 로그인·회원가입·지도·대시보드·폴더구조 등 문서 |
| `public/` | favicon, 아이콘 SVG 등 공개 정적 자산 |
| `src/` | 앱 전체 코드 |
| `.env` | `VITE_API_BASE_URL`, 카카오맵 키 등 (커밋 주의) |
| `index.html` | `#root` 마운트 포인트 |

### `docs/` 문서 목록

| 파일 | 내용 |
|---|---|
| `폴더구조.md` | **이 문서** — 현재 폴더·파일 역할 |

## 16. 아직 읽기 애매한 지점 (의도적 잔여)

1. **`authStore`가 `shared/stores`가 아니라 `src/stores/`** — 보류
2. **GOV mock은 `mocks/data/`, INS mock은 `domains/ins/mocks/`** — 위치가 다름
3. **`GovDashboardPage.module.css`가 shared에** — 페이지 파일과 CSS 폴더가 분리
4. **`signup.bak.ts`, 루트 `index.css`/`App.css`** — 레거시·미사용 가능
5. **`pages/` vs `domains/*/pages`** — 랜딩·마이·설정만 pages, 인증·대시보드는 domains

이 문서는 위 상태를 **현재 사실**로 기록한다. 추가 이동이 있으면 이 파일을 갱신하면 된다.
