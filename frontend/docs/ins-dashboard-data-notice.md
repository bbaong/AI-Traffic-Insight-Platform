# 보험사 대시보드 — 기간 드롭다운 제거 + 데이터 기준 고지

## 1. 무엇을 바꿨는지

| 항목 | 내용 |
|---|---|
| 기간 드롭다운 | 보험사 헤더의 `최근 12개월 ▾`만 숨김 |
| 하단 고지 | 지도 카드 바로 아래(mapSlot)에 데이터 기준·면책 고지 |
| 적용 범위 | **INS만**. GOV는 변경 없음 |

---

## 2. 왜 보험사에만인지

이번 요구 범위가 보험사 대시보드에 한정된다. 지자체는 기간 필터 UI·고지 문구를 별도 판단한다.

---

## 3. 공용 Shell을 어떻게 안 건드렸는지

| 대상 | 처리 |
|---|---|
| `DashboardShell` | **미수정**. 슬롯·그리드 그대로 |
| `Header` | 드롭다운을 삭제하지 않고, 기존 `role`로 **ROLE_A(지자체)일 때만** 렌더. ROLE_B는 미표시 |
| 푸터 | `InsDataNoticeFooter`를 **지도(mapSlot) 바로 아래**에만 마운트. GOV 미사용 |

---

## 4. 문구 상수

| 상수 | 파일 |
|---|---|
| `INS_DATA_PERIOD` (`2020–2025`) | `src/constants/notice.ts` |
| `INS_DATA_NOTICE` | 동일 |
| `INS_DISCLAIMER` | 동일 |

연도는 엔대시(`–`) 사용.
