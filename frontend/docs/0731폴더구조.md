# 프론트엔드 폴더 구조 (2026-07-31)

기준 경로: `frontend/`  
이 문서는 **현재 디스크에 있는 구조**를 스냅샷으로 정리한 것이다.  
(`node_modules/`, `dist/` 제외)

---

## 1. 한눈에 보는 역할 분담

| 영역 | 하는 일 |
|---|---|
| `pages/` | 라우트에 붙는 **화면 단위** (페이지) |
| `components/` | 화면을 조립하는 **UI 조각** |
| `layouts/` | 사이드바·헤더 등 **틀** |
| `app/router/` | 경로·권한 가드 |
| `api/` · `services/` | 백엔드 호출 (둘 다 존재 — 역할이 겹침) |
| `stores/` | Zustand 전역 상태 |
| `hooks/` | 재사용 로직 훅 |
| `mocks/` | 목업 데이터·핸들러 |
| `constants/` · `types/` · `utils/` · `styles/` | 상수 / 타입 / 유틸 / 디자인 토큰 |

## 2. 루트 (`frontend/`)

```
frontend/
├── docs/                 # 작업·설계 문서
├── public/               # 정적 파일 (favicon 등, 빌드 시 그대로 복사)
├── src/                  # 앱 소스 (핵심)
├── .env / .env.example   # Vite 환경변수 (카카오 키, API URL 등)
├── index.html            # SPA 진입 HTML
├── package.json          # 의존성·스크립트
├── vite.config.ts        # Vite 설정
├── tsconfig*.json        # TypeScript 설정
├── eslint.config.js      # ESLint
└── README.md
```

| 항목 | 역할 |
|---|---|
| `docs/` | 로그인·회원가입·지도·대시보드 등 작업 기록 |
| `public/` | `favicon.svg`, 로고 이미지 등 |
| `src/` | React 앱 전체 코드 |

## 3. `src/` 전체 트리 (요약)

```
src/
├── main.tsx              # ReactDOM 마운트 진입점
├── app/                  # App 루트 + 라우터
├── pages/                # 페이지(화면)
├── components/           # UI 컴포넌트
├── layouts/              # 레이아웃 쉘
├── api/                  # fetch 기반 API 함수 (현재 로그인·가입 등)
├── services/             # API 클라이언트·도메인 API (골격/확장용)
├── stores/               # Zustand 스토어
├── hooks/                # 커스텀 훅
├── mocks/                # 목업 데이터·MSW 핸들러
├── constants/            # 경로·메뉴·지도·고지 문구 등
├── types/                # TS 타입·카카오 선언
├── utils/                # 포맷·쿼리·위험도 메타 등
├── styles/               # reset / tokens / global
├── assets/               # 이미지·아이콘 리소스
├── index.css / App.css   # (레거시/보조 스타일 — styles/ 와 병존)
└── vite-env.d.ts         # import.meta.env 타입
```

## 6. 데이터·화면 흐름 (간단)

```
main.tsx
  → App
    → AppRouter
        ├─ /              LandingPage (+ components/landing)
        ├─ /login         LoginPage  → api/auth → authStore
        ├─ /signup…       가입 플로우 → api/signup
        └─ ProtectedRoute
             └─ AppLayout (Sidebar + Header)
                  ├─ /dashboard/gov        GovDashboardPage
                  ├─ /dashboard/insurance  InsDashboardPage
                  ├─ /mypage               MyPage
                  └─ /common/settings      SettingsPage
```

## 7. 구조상 눈에 띄는 점 (정리용)

| 이슈 | 설명 |
|---|---|
| `api/` vs `services/` | HTTP 레이어가 두 갈래 |
| 빈 `components/*` | chart/form/map 등 `.gitkeep`만 있는 폴더가 많음 |
| `pages/common/SettingsPage` vs `pages/settings/` | 설정 페이지 위치가 둘로 나뉨 |
| `InsDashboardPage` vs `InsuranceDashboardPage` | 보험사 대시보드 파일명 중복 가능 |
| 루트 `index.css` / `App.css` vs `styles/` | 스타일 진입점이 여러 곳 |

나중에 폴더를 단순화할 때 위 항목부터 합치거나 정리하면 체감 복잡도가 줄어든다.
